# Bubble Time

손님과 세탁기 6대·건조기 6대를 관리하는 75초 세탁소 운영 게임입니다. 오염에 맞는 도구를 골라 물때, 먼지, 놓고 간 세탁물을 처리하고 대기 줄과 환불을 관리합니다.

## 주요 기능

- 일반·성격 급한·단골·대량 세탁·희귀 평론가 손님
- 고장, 정전, 세제 부족, 단체 손님, 위생 검사 사건
- 사건 사전 예고와 6단계 실습 튜토리얼, 첫 영업 단계별 안내
- 영업마다 바뀌는 보너스 목표와 수익·점장 XP 보상
- 기계·도구 업그레이드와 매장 꾸미기
- 점장 레벨·명성, 업적, 일일 도전, 주간 목표와 매장 조건
- 최근 10회 영업 통계와 맞춤 분석, 최고 점수·진행 정보 저장
- 같은 조건 재도전, 새 목표, 상위 난이도와 해금 콘텐츠 바로가기
- S등급·무환불·점장 레벨업 전용 축하 연출과 사운드
- 공통 관리 탭, 고대비·글자 크기·모션 감소 접근성 설정
- 키보드와 모바일 터치 조작, 일시정지, PWA 오프라인 실행

## 실행

별도 빌드 과정은 없습니다. 로컬 웹 서버로 프로젝트 폴더를 열면 됩니다.

```bash
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`으로 접속하세요.

## 조작

1. 청소 또는 관리 도구를 선택합니다.
2. 오염된 기계, 손님 또는 사건 대상을 누릅니다.

숫자키 `1`–`6`으로 도구를 선택하고 `P` 또는 `Esc`로 일시정지할 수 있습니다.

## 검사

```bash
node --check script.js
node tests/laundry-game-balance.cjs
node tests/laundry-game-release.cjs
node tests/laundry-game-ui.cjs
```

UI 회귀 검사는 설치된 Chrome 또는 Edge를 헤드리스 모드로 실행합니다. 자동 탐지가 되지 않으면 `BROWSER_PATH` 환경 변수를 지정하세요. Node.js 22 이상이 필요합니다.
